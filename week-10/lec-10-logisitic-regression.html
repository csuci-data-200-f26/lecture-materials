What is it predicting?

Linear Regression Response Variables

  • Birth weight of Babies (55 - 176 ounces)
  • Sale Prices ($12789 - $755,000)
  • Number of Species (6 - 129 mammals)

Linear regression is for a continuous numeric response variable*

Or at least a discrete numeric with many possible values!

Logistic Regression Response Variables

  • Will it rain tomorrow? (Yes/No)
  • Is email spam? (Yes/No)
  • Does the candidate receive a callback? (Yes/No)

When the response variable is binary we will use a logistic regression model to get predictions for probability of [rain / spam / callback / survival]

Model reasoning

We will model probability of survival \(\pi_i\):

\[\text{transformation}(\pi_i) = b_0 + b_1x_{1i}+b_2x_{2i} +.... b_kx_{ki}\]

  • \(b_0 + b_1 \times x_{1i}+b_2 \times x_{2i} +.... b_k \times x_{ki}\) will predict values anywhere from \(-\infty\) to \(\infty\)
  • we need a transformation of \(\pi_i\) that will only predict values between 0 and 1
  • “logit” = log odds = \(log(\frac{\pi_i}{1 - \pi_i})\), is one option

Logisitic regression model

\[\text{Log Odds}_i = b_0 + b_1x_{1i}+b_2x_{2i} +.... b_kx_{ki}\]

Our first logistic model:

\[\begin{equation*} \begin{split} &\text{Log odds survival}_i = b_o + b_1 \times Age\\ &+ b_2 \times I(class = 2nd) + b_3 \times I(class = 3rd) \end{split} \end{equation*}\]

Estimating (training) our model

logisitc_model <- glm(
  survived ~ age + pclass,
  data = titanic_train_data,
  family = "binomial"
)

Getting probabilities from log odds

Logistic regression predicts log odds

\(\text{Log Odds}_i = b_0 + b_1x_{1i}+b_2x_{2i} +.... b_kx_{ki}\)

Converting back to probability:

\(\large{\pi_i = \frac{e^{b_0 + b_1x_{1i}+b_2x_{2i} +.... b_kx_{ki}}}{1+e^{b_0 + b_1x_{1i}+b_2x_{2i} +.... b_kx_{ki}}}}\)

Luckily R has functions that will help us transform from predicted log odds to predicted probability!

Predicting someone’s probability of survival

predict(
  logisitc_model, 
  newdata = data.frame(age = 25, pclass = "1st"), 
  type = "response"
)
        1 
0.7492763

Predicted probability of survival for someone 25 years old with a 1st class ticket is 0.75.

type = “response” is necessary to convert predicted log odds to predicted probability!

Model evaluation

Prediction accuracy

How do we decide if our model is predicting well?

One measure is accuracy = proportion of predictions made correctly

\[\text{Accuracy} = \frac{\text{Number of correct predictions}}{\text{Total number of predictions}}\]

But what is a “correct prediction”

Predicted probability to predicted survival

Since our original survived variable is binary (yes / no), we want to convert our predicted probabilities into either a 0 or a 1:

  • use a cutoff to convert predicted probability of survival to 0/1. For example:
    • If predicted probability survival \(\geq\) 0.5, predict survival
    • If predicted probability callback < 0.5, predict did not survive

Converting predictions with R

# Get predicted survival probability for new data
titanic_test_data <- titanic_test_data |> 
  mutate(pred_survival_prob = predict(
    logisitc_model, 
    newdata = titanic_test_data, 
    type = "response"
  )
)

# Convert predicted probability to predicted survival
titanic_test_data <- titanic_test_data |> 
  mutate(pred_survival = if_else(
    pred_survival_prob > 0.5,
    true = 1,
    false = 0
  ))
