# Dataset sources

These datasets are used in my DATA 200: Introduction to Data Science class.

## Most populat baby names

The Most Popular Baby Names data called `california-popular-baby-names` comes from [California Open Data Portal](https://data.ca.gov/dataset/most-popular-baby-names) downloaded on 2026-08-23.

## CDC viral hepatitis surveillance

The `HepTracker_Dashboard_20260914.csv` dataset comes from [CDC: Centers for Disease Control and Prevention](https://data.cdc.gov/National-Center-for-HIV-Viral-Hepatitis-STD-and-TB/HepTracker-Dashboard/jkcx-ndu8/about_data) and was downloaded on 2026-09-14. This dataset is used to create [HepTracker: Viral Hepatitis Surveillance Data Dashboard](https://www.cdc.gov/hepatitis/php/data-research/heptracker/index.html).

## Los Angeles Police Department payroll 

The `Police_payroll.csv` dataset comes from [LA City Controller](https://controllerdata.lacity.org/Payroll/Police-Payroll/sxpf-rh6t) and contains data from 2013-2018.
